# workrr Private-Tier Hash-Only Anchor (`services/private-anchor`)

Cloudflare Worker on D1 that anchors private-tier Sigstore attestations publicly **by SHA-256 hash only**, proving existence and time in an append-only hash chain while keeping artifact names, source repositories, policies, and predicates confidential.

## Endpoints

- **`POST /v1/anchors`** — Accepts `{ "envelopeHash": "<64-hex>", "bundleHash": "<64-hex>", "subjectDigestHash": "<64-hex>" }` (generated by `workrr anchor <path> --bundle <bundle.sigstore.json>`) and returns a hash-chained `AnchorReceipt`. Any non-hash field is rejected with `400`.
- **`GET /v1/anchors/:hash`** — Looks up an anchor receipt by `envelopeHash` or `bundleHash`.
- **`GET /v1/anchors/head`** — Returns the latest chain head (`sequence`, `chainHash`, `anchoredAt`).

## Verification

```bash
workrr verify ./skills/private-skill \
  --bundle certificate.sigstore.json \
  --private \
  --trusted-root github-private-trusted-root.json \
  --anchor-receipt receipt.json
```
